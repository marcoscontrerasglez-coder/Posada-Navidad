# INVITACION WEB - POSADA NAVIDEÑA

## PRUEBA LOCAL

1. Abre la carpeta del proyecto.
2. Edita:
   js/config.js
3. Coloca tu música:
   assets/navidad.mp3
4. Opcionalmente coloca:
   assets/portada.jpg
5. Abre index.html con Google Chrome.

## DATOS EDITABLES

Todo lo principal está en:

js/config.js

Puedes modificar:

- nombre
- fecha
- hora
- lugar
- direccion
- googleMapsUrl
- mensaje
- estilo
- musica
- imagenPortada

## ESTILOS

Usa uno de estos valores:

elegante
tradicional
nieve
oscuro
festivo

## IMPORTANTE SOBRE LA MUSICA

Los navegadores normalmente bloquean el autoplay con sonido.
Por eso la página tiene un botón "Activar música".

## MAPA

El mapa usa la dirección configurada y Google Maps.
Para una ubicación más precisa puedes colocar un enlace de Google Maps
en googleMapsUrl.
